## Status

This is an **Internet-Draft**, a work in progress.
It does not represent IETF consensus and may be updated, replaced,
or obsoleted at any time.

## Scope

ARDP defines a **control-plane protocol** for:
- stable agent identification
- registration and discovery
- capability advertisement and protocol selection

ARDP explicitly does **not** define:
- agent reasoning or planning
- task execution semantics
- tool or workflow protocols
